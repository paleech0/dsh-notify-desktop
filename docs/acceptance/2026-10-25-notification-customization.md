# 按情况自定义音效与弹窗文本 — 验收记录（2026-10-25）

**状态：随 0.2.0 发布。** 实机验证（DSH 桌面端 0.2.1-rc.3）：宿主加载、文本模板路由保存/删除
（UTF-8 中文往返、磁盘落盘、字节级还原）、设置页的预览 / 测试通知 / 静音 / 转换缓存清理均通过；
视觉细节按下方清单人工过目。
本轮替换掉「通知形式重构」里的「4 组音效 + 全局标题/正文模板」部分（那份验收记录的 UI 章节自此过时）。

## 本轮改动

- **情况（scenario）成为唯一分组键**：9 个（5 个结束原因 / 3 种等待 / 1 个催办），音效与文本都按情况存；
  「4 组音效」概念移除，旧 `sounds.finished/error/attention/reminder` 在 `readSettings` 里按组下发迁移。
- **弹窗文本按情况自定义**：每个情况最多 3 套，每套有名称（≤24）/标题（≤120）/正文（≤300）、占位符
  `{工作区} {状态} {内容} {分钟}`、行内编辑器带实时预览和点击插入；内容存
  `%LOCALAPPDATA%\dsh-notify\templates\templates.json`（原子写、损坏容错、宿主校验上限）。
- **宿主新路由**：`GET/POST /dsh-notify/text-templates`（`src/text-store.ts`）。
- **客户端文本库缓存**：`src/client/texts.ts`，启动加载一次、编辑后回填，通知链路按情况取文本与音效。
- **设置页重排为三卡**（2026-10-25 二次调整顺序：情况选择卡挪到总开关卡下方）：
  1. 桌面通知：总开关 → 发送测试通知（说明加「用于检测配置是否正常」）→ 通知形式三选一；
  2. 选择接收以下哪种情况的通知：「会话结束」5 个开关、「等待你确认」3 个开关，每行带一句例子
     （已去掉「例：」前缀）；
  3. 通知自定义：已勾选情况的行（音效 + 文本 + 预览效果）→ 自定义音效折叠（含转换缓存）→ 自定义文本折叠
     （按情况管理，编辑 + 红色删除 + 行内二次确认）。
- **交互细节**：情况行随勾选实时增减；取消勾选只隐藏、已配内容保留；总开关关闭时交付控件灰显，
  仅两个可折叠库仍可编辑；测试通知固定文案 + `system:default`；预览用真实文本与音效并跟随通知形式。
- **旧全局模板迁移**：若旧 `titleTemplate/bodyTemplate` 非默认，启动后写入每个已启用情况的文本库并选中，
  成功才清掉 `legacyText`（失败下次启动重试，已有同内容模板则不重复创建）。
