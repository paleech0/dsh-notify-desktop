## rc.3 seam 复核（源码取自 `app.asar` 内 `dsh/node_modules/@deepseek-ai/*` 0.2.2-rc.3）

宿主：

- `ctx.sessionProjections.register(definition)` 返回 **`Promise<ProjectionHandle<S>>`**（await 后 `stateOf(session)`）；
  `ProjectionDefinition` 的 `key / stateSchema / stateVersion / init(header, inheritedEventCount) / apply /
  wire{viewSchema, view}` 与插件定义形状一致；`snapshot(session).values` 仍可用（debug 路由实证）。
- 上游 `stateOf(session, key)` 仍存在但已标弃用；插件自 0.2.2 起改为 await 注册句柄，不受影响。
- 宿主 `sessions.list()`、`webServer.register({ kind: 'exact', path, handler })` 未变。
- `user-questions/request` 瀑布仍在；`AskUserQuestionRequestEvent` 的 `questions / agent / wait` 与插件读取一致；
  `dsh-user-questions` 自身也用 `{ global: true }` 监听，说明全局选项有效。
- 事件形状未变：`turn/end { turn, reason: { kind } }`（completed / aborted / blocked / error / max-tokens /
  interrupted / forked；插件按设计静默后两者）、`approval/asked { id, toolName, reason? }`、
  `approval/decided { id, outcome }`、`tool/call { callId, name, arguments: string }`、`tool/ptc-dispatch*`。

客户端：

- `sessions.list` 为 ObservableSnapshot（`getSnapshot` / `subscribe`）、`uiWorkspace.openSession`、
  `slots.register(options, component)` / `slots.inject('settings.section')`、
  `locale.register(ns, { zh, en })` / `getSnapshot().active` / `subscribe`、`connection/reset` 均存在。
